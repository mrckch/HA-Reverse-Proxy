Hilfe & Links

  • Service hinzufügen: nginx/sites-available/<name>.conf committen, dann auf jeder Node sudo /opt/reverse-proxy/scripts/enable-site.sh <name>
  • Cert anfordern (nur MASTER): sudo /opt/reverse-proxy/scripts/cert-request.sh <domain>
  • Failover testen: sudo systemctl stop nginx auf dem MASTER — Floating-IP sollte in ~3s zum BACKUP wechseln
  • Bootstrap erneut starten: sudo /opt/reverse-proxy/scripts/bootstrap.sh (idempotent)
  • Deploy-Log: tail -f /var/log/proxy-deploy.log
  • Bootstrap-Log: tail -f /var/log/proxy-bootstrap.log
